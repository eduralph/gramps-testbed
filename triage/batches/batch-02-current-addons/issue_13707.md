## Description
MacOS ARM 6.0 rc2. Tried to install DE Web Connect Pack. The description says it requires libwebconnect, but the AddonManager does not have a Requires in the GPR. So the install fails if libwebconnect is not installed. 

Gramplet should be updated to use the requires option in the GPR.

## Steps to Reproduce
Running 6.0 attempt to install DE Web Connect when libwebconnect is not installed.
