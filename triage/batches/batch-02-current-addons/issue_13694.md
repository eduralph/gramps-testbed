## Description
If an addon has include_in_listing=False, and if you run make.py gramps60 listing <Addon> , then the JSON files become corrupted.

## Steps to Reproduce
In the addons-source folder, enter
make.py gramps60 listing Query

Inspect the JSON files generated in addons/gramps60/listings/ folder. They are all corrupt.

## Tracker discussion (Mantis notes, scraped)

**Note 1** (prculley - 2025-05-15 16:02)

The "make.py gramps60 listing" command is designed to either add a new addon, or to update existing addon(s). It is NOT designed to unlist an addon. In fact if you have just modified the gpr.py file to add "include_in_listing=False" and then run this with the "all" option, it will not change the listings for that addon, the addon will remain included.

To unlist an addon you have to either use the "unlist" command, or the "as-needed" command, either should remove the addon from the listing.
