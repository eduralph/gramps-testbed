## Description
I experience a problem with varying font size when creating a graphical report of a fan chart. The font size seems to vary across generation, but inconsistently, with sometimes small fonts when there is much more space available in the box. In the attached example, fonts are very small in the sixth (yellow) generation, but much bigger in the 9th generation (orange).  I tried using a custom style with font sizes defined for each generation, but that is not reflected in the exported fan chart. I have added an example. Does someone have a solution, or could explain what I am doing wrong?
