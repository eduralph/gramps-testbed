## Description
Download, please, the dummy file with people from Simpson family.
As you can see I assigned to Abraham Simpson a date of birth equale to 1/1/1800.
By running the tool from menu: Tools > Utility > Verify the data using defaults (102, 17, 50, 3, 30, 99, checked, checked)
the outcome I get is: Old age but no death (1)

So I returned to Abraham Simpson and I assigned him an empty death date.
Now, running the same tool once again the outcome is: Invalid death date (1)

In my real family tree I have a lot of person without death date.
Using old gramps release (< 6.0.0) I assigned them an empty death date and all was fine with the "Verify the data" tool.

To understand why the previous empty dates are, today, still accepted by the "Verify the data" tool
while the last one added today using gramps 6.0.0 is not accepted
I exported my tree to "Gramps XML (family tree)"

What I found is that with old gramps releases and empty date of death was saved as:

    <event handle="_efd2aa014bf727de9021bcde2f6" change="1690032951" id="E1589">
      <type>Death</type>
    </event>

while the last empty date of death was saved, today, as:

    <event handle="_fdafda5357832b98a1e0be2fae0" change="1743323274" id="E3107">
      <type>Death</type>
      <datestr val=""/>
    </event>

is this an error of Gramps 6.0.0 core or of the "Verify the data" tool?
