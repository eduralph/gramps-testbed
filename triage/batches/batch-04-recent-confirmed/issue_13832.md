**Note 10** (dstraub - 2025-05-16 04:58)

Hi, handles created in the Gramps Web frontend use UUIDv4 for handles to make sure they are unique, and those UUIDv4s do include hyphens, yes. The Gramps object schema requires handles to be strings with at most 50 characters length, with no other restrictions. I am not aware of this having changed. In my opinion, not handling arbitrary strings conforming with the required schemas is a bug.

https://github.com/gramps-project/gramps-web/blob/main/src/util.js#L370-L372
