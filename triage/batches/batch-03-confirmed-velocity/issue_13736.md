## Description
Upgrading to from 5.2 to 6.0 may have 3rd-party 5.2 "Projects" in the "addons-projects" portion of the gramps-ini [behavior] chunk. The addons-xx.json will have incompatible "Gramps target version"s. But the registration failure  message is not helpful in determining that.

“Addon registration Failed - The addon will be unavailable in your current configuration”

## Steps to Reproduce
have a Gramps 5.2 gramps.ini that has external 5.2 projects (such as Isotammi, FamilySearch, FamilyTreeView, GlopGlop)

Either upgrade to 6.0 (or rename the 6.0 gramps.ini so that the 5.2 configuration will be imported again. Rename the gramps60/plugins folder for this test too.)
start Gramps 6.0
in the Addon Manager, confirm that the 5.2 projects are still in the path
attempt to install addons

“Addon registration Failed - The addon will be unavailable in your current configuration”
in addition a "installation errors" dialog, listing of all the addons and their version (not the Gramps target version), will be generated

Neither states the problem: that the plugins are for a different version of Gramps. Nor does it mention the "Project" name with the mismatched versions. 

A solution would be to give a more explicit error message.  The user can be responsible for corrective action. (Since they originally added the projects manually. If Gramps added a third party curated addon collection, then it would bear that responsibility.)
