## Thread — architectural, with a maintainer-blessed NARROW fix
prculley (note 4): Forms editor has no protection against changes made outside it while
open; deleting a referenced source/person/place mid-edit corrupts the db on OK.
nick_h (notes 5,7): KNOWN issue, documented, low priority (10 years, first report). It's
part of the bigger snapshot-write-back problem (editors save a stale snapshot). The
EASIEST acceptable fix WITHOUT removing functionality:
  - Check the source still exists when saving; if not, create it.
  - Check the person still exists when saving; if not, discard the row.
