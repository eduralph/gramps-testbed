**Note 8** (prculley - 2020-11-12 17:04)

You guys have found out why the developers decided not to use the SQLite db with the tables formatted this way. We decided to use the blobs instead. This format, while very much more readable by the sophisticated user, is far slower to read because each lookup on a person (for instance) can result in hundreds of queries as each sub-object about a person (list of names(name, (list of surnames, (surname)) first name etc.)) is looked up in turn. And this is true for each object type.
