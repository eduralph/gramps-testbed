## Description
When I use the map service to locate a place for which I only entered a name (and a type and code), it tries to open it in the web browser and search it with Nominatim, but it always ends with a 404 error.
The URL it sends me to is: http://nominatim.openstreetmap.org/search.php?q={%s}, which the website immediately redirects to https://nominatim.openstreetmap.org/ui/search.php.html?q={%s} (%s usually being a city name for example).
<b>The URL it should use is: http://nominatim.openstreetmap.org/search?q={%s}</b> (.php removed), which then correctly redirects to https://nominatim.openstreetmap.org/ui/search.html?q={%s}.

I am using the French version of it, so the features’ names may be badly translated.
Also, I do not know if it is a 3rd party add-on or not.

## Steps to Reproduce
Right-click on a place for which the coordinates have not been completed and use the “Search with the map service”.

**Note 3** (daleathan - 2023-10-21 01:01)

https://nominatim.openstreetmap.org/search/

Shows:

File not found: API no longer accessible via this URL

Using the URL /search/ and /reverse/ (with slashes) is no longer supported. Please use URLs as given in the documentation.

Examples how to change the URL:

You use: https://nominatim.openstreetmap.org/search/?q=Berlin
Change to: https://nominatim.openstreetmap.org/search?q=Berlin

You use: https://nominatim.openstreetmap.org/search/US/Texas/Huston
Change to: https://nominatim.openstreetmap.org/search?q=Huston, Texas, US

See github issue https://github.com/osm-search/Nominatim/issues/3134 for more details.
