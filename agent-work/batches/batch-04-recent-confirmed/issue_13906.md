## Description
gramps fails to update isotammi addons if in French : gramps should fallback to lang-en.json if lang-XX.json doesn't exist

On #13889 I was told to update isotammi.
But gramps didn't offered to update isotammi addons.
However I could see the following on the CLI:
2025-07-15 17:31:32.796: WARNING: utils.py: line 239: Failed to open addon metadata for fr https://raw.githubusercontent.com/Taapeli/isotammi-addons/master/addons/gramps60/listings/addons-fr.json: HTTP Error 404: Not Found

Note the "addons-fr.json" part

Indeed listings only exists for a cople languages on https://github.com/Taapeli/isotammi-addons/tree/master/addons/gramps60/listings
Gramps should fallback on lang-en.json if lang-LL.jons doesn't exist (with "LL" being the current used locale).
Currently gramps is very broken for most non english users regarding installing/updating third party addons.

It could be the same for gramps own addons as not all locales can possibly be listed on https://github.com/gramps-project/addons/tree/master/gramps60/listings (especially not all ll_LL variants)

I'll try restart gramps in english for the addons manager to work…

## Steps to Reproduce
run gramps in French.
eg:
cat > .i18n.fr <<EOF
LANGUAGE=fr:fr_FR:fr
LC_NUMERIC=fr_FR.UTF-8
LC_PAPER=fr_FR.UTF-8
LC_TIME=fr_FR.UTF-8
LANG=fr_FR.UTF-8
LC_MEASUREMENT=fr_FR.UTF-8
LC_MESSAGES=fr_FR.UTF-8
LC_CTYPE=fr_FR.UTF-8
LC_TELEPHONE=fr_FR.UTF-8
LC_ADDRESS=fr_FR.UTF-8
LC_NAME=fr_FR.UTF-8
LC_IDENTIFICATION=fr_FR.UTF-8
LC_MONETARY=fr_FR.UTF-8
LC_COLLATE=fr_FR.UTF-8
EOF
 (. ~/.i18n.fr;gramps )&

Set up isotammi addons according to https://github.com/Taapeli/isotammi-addons
See that you cannot install/update addons if in French.
Restart in English : it now works…
