**Note 2** (jralls - 2026-05-18 14:25)

That PR will make the Addon Manager install plugin dependencies. It should be in Gramps 6.1.0.

In the meantime: Gramps.app has its own instance of Python and it pays no attention to the python in the environment. To get the plugin to work you need to put boto3 and its dependencies where Gramps can find it. On macOS that's $HOME/Library/Application Support/gramps/gramps60/plugins/lib/
You need the following packages: boto3, botocore, s3transfer, and jmespath. They're all pure python so you can just copy them from your virtenv's lib/python3.xx/site-packages to gramps60/plugins/lib.
