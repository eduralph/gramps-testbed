## Description
delete selected Citation rows in the Citation Tree view mode does not actually complete the deletion

## Steps to Reproduce
create a new blank tree and import the example.gramps tree
in the Sources category, select the Citation Tree view mode
expand the World of the Wierd source group

select one of the 2 Citation rows (but NOT a source row)
click the Delete toolbar button or select Edit -> Delete

2 successive confirmation dialogs appear with the identical main content 
   (the 1st dialog has a title that identifies the records as "Citation" type and has Cancel/Delete buttons,
   (the 2nd dialog has a title that just has a "Delete" plus the GrampsID and has Cancel/No/Yes buttons)

after confirming both dialogs, nothing changes

If more than 1 record was selected, there is only 1 dialog that has an checkbox option to use the answer for the rest of the items.   But again, only Source rows (and that source's citation) are deleted. Selected Citation rows are not deleted (unless the parent Source row was also selected for deletion)
