## Tracker discussion (Mantis notes, scraped)

**Note 1** (garygriffin - 2025-04-17 19:24)

This addon has prerequisites that are not satisfied. These are life_line_chart and svgwrite.

https://gramps-project.org/wiki/index.php?title=Addon:Life_Line_Chart_View#Prerequisites

The Plugin Manager Enhanced will not allow you to download this plugin without satisfying the prereqs first.
The standard Plugin Manager will allow you but lists the missing prereqs.

Installing these prereqs on a Mac is an advanced task. If you are an advanced user, you can use pip install to load them onto your OS and then move them (and any dependencies) into the Gramps app itself.

You can get more details in the Discourse forum on installing missing dependencies. https://gramps.discourse.group/t/workaround-for-installing-missing-python-module/7304/8
