**Note 6** (jralls - 2025-09-11 20:30)

But searching for "Managing Names" in Gramps's de.po finds it in a tip of the day, so it's the tip of the day window. Knowing that, I'm able to reproduce the screenshot by putting Gramps in full screen and having show the tip of the day at startup enabled, then quitting and restarting Gramps. When I do that the buttons are still sensitive, but clicking either of them crashes Gramps in Gtk drawing code. The family tree title bar at the top is a tab drawn by macOS; it's not part of the Gtk window. The other tab is partly visible in the screen shot, but its title isn't. The tip of the day drawing is obviously screwed up to the point that we didn't recognize it, plus the main window tab has focus so the TotD shouldn't even be visible.Clicking in the TotD area switches focus, after which one can click on the main window tab to swtich focus back and then it will draw the main window, but it doesn't work well and will soon crash in the same place that the TotD buttons do.

I found two possible workarounds: Turn off showing the TotD at startup or leave full screen before quitting Gramps so that it doesn't start up in full screen.

I thnk the problem is in how Gtk renders multiple windows in full screen. It wasn't something I took into account when I rewrote the Gtk3 macOS rendering code a few years ago. I doubt that I'll have time to fix it any time soon.

**Note 10** (jralls - 2025-09-18 14:18)

@OlliR The bars at the top of the screen--your screenshots show two but I think, particularly in the last one, there are more--are tabs for the different windows. That error dialog belongs to one of them but it's not the selected one so it can't get focus, but it's modal so it's blocking everything else from doing anything. You can switch which window is displayed by clicking the different tabs and you might be able to get the error dialog both displayed and responsive by switching to the window that's displaying it.

But Gramps isn't really designed for full-screen operation: It opens far too many windows and many of them don't render well in full-screen, the Tips window being a prime example. You'll get better behavior by switching off full-screen and maximizing the windows.
