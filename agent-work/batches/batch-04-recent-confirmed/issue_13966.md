## Description
When Prerequisites Checker is installed, and the Prerequisites Checker gramplet is added to the Dashboard, closing a family tree will result in these messages in the console:

2025-08-30 09:00:29.247: WARNING: _gramplet.py: line 347: Gramplet gave an error: Prerequisites Checker
Traceback (most recent call last):
  File "C:\Users\codefarmer\AppData\Local\Programs\GrampsAIO64-6.0.4\gramps\gen\plug\_gramplet.py", line 331, in _updater
    retval = next(self._generator)
             ^^^^^^^^^^^^^^^^^^^^^
  File "C:\Users\codefarmer\AppData\Roaming\gramps\gramps60\plugins\PrerequisitesCheckerGramplet\PrerequisitesCheckerGramplet.py", line 171, in main
    if self.uistate.viewmanager.active_page.bottombar:
       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
AttributeError: 'NoneType' object has no attribute 'bottombar'
Continuing after gramplet error...

## Steps to Reproduce
1. Install Prerequisites Checker 
2. Add Prerequisites Checker to your Dashboard page
3. Open a family tree
4. When on the Dashboard page, close the family tree

Expected: clean close, no exceptions in console
Actual: Exception messages in console as shown in Description

Can reproduce this in Gramps 5.2.4 as well, with just the source code line numbers being slightly different.

## Tracker discussion (Mantis notes, scraped)

**Note 1** (eduralph - 2026-05-23 16:09)

PR opened against addons-source maintenance/gramps61: https://github.com/gramps-project/addons-source/pull/913

Root cause: PrerequisitesCheckerGramplet.main() is a generator the framework keeps stepping via _updater -> next(self._generator) after the tree is closed. At that point self.uistate.viewmanager.active_page is None, so the unguarded read of ctive_page.bottombar raises the AttributeError shown in the report.

Fix: read active_page into a local and return early when it is None; the existing bottombar / db-open / count<3 short-circuit chain otherwise runs unchanged. Regression test exercises main() with a stub uistate whose active_page is None reproduces the exact traceback pre-fix) plus two guard cases that lock the dashboard / non-dashboard short-circuit paths.
