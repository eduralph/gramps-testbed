## Description
As discussed in this forum topic:
https://gramps.discourse.group/t/undo-in-notes-not-working-as-expected-after-pasting-text/5266

When in the Notes editor, working in a note that is long enough to have a scroll bar, pressing undo also scrolls the editor to the top/first line.
Making the user having to scroll down to where they were again.

## Steps to Reproduce
Have a Note that is long enough to have to scroll to get to the bottom.
Be scrolled down to the bottom, and press undo.
Editor jumps to the top of the file.
