**Comment to paste:**
> Per the investigation in this thread (notes ~0061351 and ~0061365): the SQLite import
> completes but is far slower than XML import (~8 hours vs minutes for ~95k people),
> because the addon's normalized table layout requires many queries per object. This is a
> known design tradeoff — the core database uses blobs to avoid it. The import is not
> hung. Closing as no-change-required. The one actionable item raised (an Abort button so
> users need not force-kill Gramps during a long import) is tracked separately as an
